# Kaspi Price Bot v4

Версия с выбором категории и объёма для масел/технических жидкостей.

### Параметры
- НДС: 16%
- ИПН: 10% (модель калькулятора)
- Чистая целевая маржа: 20%
- Доставка: 100 ₸
- Упаковка: 100 ₸
- Социальные платежи: не учитываются
- Закупочная цена вводится уже с НДС
- Комиссия Kaspi подставляется автоматически

Для категории «Масла и технические жидкости» бот дополнительно предлагает:
1 л, 4 л, 5 л, 20 л.

## Запуск

```bash
pip install -r requirements.txt
```

Windows CMD:
```cmd
set BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
python bot.py
```

PowerShell:
```powershell
$env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
python bot.py
```
